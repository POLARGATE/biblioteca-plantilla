# Tu biblioteca de Polargate

Este repo es la plantilla de [biblioteca.polargate.ai](https://biblioteca.polargate.ai). Créalo
privado desde el apartado GitHub de tu cuenta e instala la app polargate-biblioteca solo en él.

La app comprueba que el repo sale de esta plantilla antes de escribir: el fichero
`.claude-plugin/marketplace.json` tiene que llamarse `polargate-biblioteca`. La primera entrega
reescribe este README con lo que has recibido.
